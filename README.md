# Agent - Automated X Posting with Claude Code

A powerful, intelligent agent that automatically posts content to X (formerly Twitter) using Claude Code and the Claude SDK.

## Quick Start

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set up your Claude API Key and X credentials
4. Run: `python agent.py`

## Documentation

For detailed setup and usage instructions, see [REPO_TOUR.md](REPO_TOUR.md)

## Features

- 🤖 Intelligent content generation with Claude Code
- 📅 Scheduled posting automation
- 🔐 Secure credential management
- 📊 Metrics and logging
- 🛡️ Rate limit handling

## Requirements

- Python 3.9+
- Claude API Key
- X API Credentials
